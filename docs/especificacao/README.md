# Especificação

Artefatos técnicos que antecedem a implementação.

- `parametros-contato.md` — cadência de disparo e regras de contato (E05)
- `capacidades-plataforma.md` — conferência das capacidades C1 a C10 contra a
  instância viva, e registro da versão e da configuração aplicada (E08)
- `leitura-devolucoes.md` — como o parâmetro P8 é implementado: desenho do correio
  de ensaio, classificação do retorno e onde cada estado é gravado (E09)
- `leiaute-entrada.md` — arquivo que popula a base de participantes (E11)
- `blocos-instrumento.md` — blocos estruturais e domínios de valores (E12, E13)
- `navegacao-condicional.md` — regras de navegação (E14), com a conferência na
  plataforma (E15)
- `importacao-base.md` — validação prévia, base central, precedência e trilha da
  importação (E17)
- `pre-preenchimento.md` — acesso por token, pré-preenchimento da identificação,
  fila de revisão e ativação (E18)
- `matriz-verificacao.md` — critério de aceite do mecanismo (E25)
