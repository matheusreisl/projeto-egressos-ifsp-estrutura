# Dados

Apenas bases sintéticas, geradas por script.

`sinteticos/` guarda as bases produzidas. O conteúdo gerado não é versionado —
o que se versiona é o script que o produz, garantindo reprodutibilidade.

Para gerar a base de validação, da raiz do repositório:

    python3 scripts/gerar_base_sintetica.py

Ver [`scripts/README.md`](../scripts/README.md), "A base sintética".

Nunca colocar aqui dados de pessoas reais, nem parciais, nem "de exemplo".
